# Phase 2.5: one path contract and a sync folder, implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** every file the launcher and the prompt runner use is found through one pure module, `lib/Paths.js`, and a sync folder (`general.syncDir`) moves the files you curate into a folder you sync between machines, with fill, join and leave, and read-only while the folder is missing.

**Architecture:** `lib/Paths.js` (ES5, pure, no I/O) computes every path, splits and combines the two settings files, and plans a sync change as a list of steps. `scripts/sync-apply.sh` runs those steps. The runner reaches `Paths.js` through `daemon/lib/paths.mjs` (an installed runner has a copy, `lib/shared-paths.cjs`) and writes synced files only through `daemon/lib/atomic.mjs`. `Service.qml` binds every `FileView` to `Paths.resolve`'s result.

**Tech Stack:** ES5 JavaScript (`lib/`, shared with QML and JavaScriptCore), Node 22 ESM (`daemon/`), `node --test` (CommonJS test files), bash, QML (Quickshell).

**Spec:** `docs/superpowers/specs/2026-10-12-phase-2.5-paths-design.md`. Read it first; this plan implements it.

## Global Constraints

- `lib/*.js` stays ES5: `var`, `function`, no `let`/`const`/arrows/template literals; exports through `if (typeof module !== "undefined") module.exports = {...}`; no `require` between `lib/` files (dependencies come in as arguments).
- Node 22 or newer for `daemon/` and the tests. Test files are CommonJS (`require`); they load `daemon/` ES modules with `await import(...)`.
- No new dependencies, in `daemon/package.json` or anywhere.
- Shell scripts: bash, `set -euo pipefail`, BSD and GNU safe (no `\s` in `sed`, no GNU-only flags).
- Exact names: the marker `oma-zotero-sync.json`; backups in `<config dir>/sync-backups/<YYYY-MM-DD-HHMMSS>`; problem codes `sync-unavailable` and `sync-dir-invalid`; the message `Sync folder not found: <path>`.
- With no sync folder set, every path and every byte written is what it is today (the first case of `tests/fixtures/paths.json`).
- No em dashes in any text: code comments, docs, commit messages, UI strings.
- Commits: a plain descriptive subject, as in this repository's history, ending with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Tasks 1 to 7 and 10 run anywhere with Node (`make test`). Tasks 8 and 9 change QML: `make lint` (qmllint) runs on the Omarchy machine and in CI; their behavior is checked in Task 11's checklist.

## Review Focus

1. **Leaving while the sync folder is missing** (an unmounted drive, a renamed folder): your local files must stay as they are, not go to the backup with nothing to replace them. Task 3, test "leave with the sync folder gone".
2. **Saving settings while the sync folder is missing:** a change to this machine's keys (a port, a command) must still save; a change to a shared key must be refused with the message, never written elsewhere. Task 2, test "settingsSave with the sync folder missing".
3. **A rerun after a plan failed half-way** (a full disk, a permission): it must finish the job without nesting a copied folder inside itself or failing on what already moved. Task 4, tests "run twice: the same result" and "move: done once, skipped on a rerun".
4. **`/etc/hostname` ends with a newline**, and a machine name typed with spaces: the machine's name must be trimmed, or the automation host never matches. Task 1, fixture "a hostname as /etc/hostname has it".
5. **`XDG_CONFIG_HOME` set somewhere else:** the launcher must find the settings file where the runner does (today they differ: the QML ignores `XDG_CONFIG_HOME`). Task 1, test "settingsFile: from the environment only"; Task 10 notes it in the CHANGELOG.

```js
// Where every file lives, for the launcher, the prompt runner and the macOS app alike: one answer
// for the three (zotero-launcher-macos PLAN.md, decisions 8 and 12). Pure: the callers read, probe
// and write; this only computes. A sync folder (general.syncDir) moves the files you curate under
// <syncDir>/shared, a folder you sync between machines yourself (Syncthing, Dropbox).
// Design: docs/superpowers/specs/2026-10-12-phase-2.5-paths-design.md.

var MARKER = "oma-zotero-sync.json"
var STIGNORE = "*.tmp\n.DS_Store\n"

// What moves under the sync folder, in the order a plan copies it.
var SYNCED = ["pins", "searches", "todos", "view", "instructions", "prompts", "taxonomies", "taxonomyState", "chats", "artifacts"]

// Which settings travel (shared) and which stay on each machine; anything not listed stays.
var SETTING_SCOPES = {
  "general.port": "machine", "general.externalPdfCommand": "machine", "general.promptCommand": "machine",
  "general.zoteroCommand": "machine", "general.artifactsDir": "machine", "general.syncDir": "machine", "general.machineName": "machine",
  "general.enterAction": "shared", "general.maxResults": "shared", "general.accelerators": "shared", "general.emptyQuery": "shared",
  "general.keys": "shared", "general.keysStart": "shared", "general.keyDelay": "shared", "general.citationStyle": "shared",
  "general.automationHost": "shared",
  providers: "shared", defaults: "shared", tasks: "shared", status: "shared", rules: "shared"
}

function isObject(x) {
  return !!x && typeof x === "object" && !Array.isArray(x)
}

function clone(x) {
  return x === undefined ? undefined : JSON.parse(JSON.stringify(x))
}

// ("/a/", "b") → "/a/b": empty parts skipped, no doubled or trailing slashes.
function join() {
  var parts = []
  for (var i = 0; i < arguments.length; i++) if (arguments[i]) parts.push(String(arguments[i]))
  var s = parts.join("/").replace(/\/{2,}/g, "/")
  return s.length > 1 ? s.replace(/\/$/, "") : s
}

function baseName(p) {
  var s = String(p)
  return s.slice(s.lastIndexOf("/") + 1)
}

function expandHome(p, home) {
  var s = String(p)
  if (s === "~") return home
  if (s.indexOf("~/") === 0) return join(home, s.slice(2))
  return s
}

// A general key of the settings file: its "general" section, else a flat key from before sections.
function generalValue(raw, key) {
  if (!isObject(raw)) return undefined
  if (isObject(raw.general) && raw.general[key] !== undefined) return raw.general[key]
  return raw[key]
}

function bases(env) {
  var e = env || {}
  var home = e.HOME || ""
  var config = e.XDG_CONFIG_HOME || join(home, ".config")
  return {
    home: home,
    config: config,
    cdir: join(config, "omarchy", "oma-zotero-launcher"),
    state: join(e.XDG_STATE_HOME || join(home, ".local", "state"), "oma-zotero"),
    cache: join(e.XDG_CACHE_HOME || join(home, ".cache"), "oma-zotero-launcher")
  }
}

// The machine settings file: from the environment only (it holds the sync folder itself).
function settingsFile(env) {
  return join(bases(env).config, "omarchy", "oma-zotero-launcher.json")
}

// Every other path. env: { HOME, XDG_CONFIG_HOME, XDG_STATE_HOME, XDG_CACHE_HOME,
// OMA_ZOTERO_PROMPTS_DIR, OMA_ZOTERO_INSTRUCTIONS, hostname }; machineSettings: the parsed machine
// file or null; probe: { syncMarker } (does <syncDir>/shared/oma-zotero-sync.json exist).
function resolve(env, machineSettings, probe) {
  var e = env || {}
  var b = bases(e)
  var problems = []
  var syncDir = null
  var wanted = generalValue(machineSettings, "syncDir")
  if (typeof wanted === "string" && wanted.trim()) {
    var abs = expandHome(wanted.trim(), b.home)
    if (abs.charAt(0) === "/") syncDir = join(abs)
    else problems.push("sync-dir-invalid")
  } else if (wanted !== undefined && wanted !== null && wanted !== "") problems.push("sync-dir-invalid")
  var shared = syncDir ? join(syncDir, "shared") : ""
  function place(name, local) { return shared ? join(shared, name) : local }
  var artifactsDir = generalValue(machineSettings, "artifactsDir")
  var name = generalValue(machineSettings, "machineName")
  var out = {
    settings: settingsFile(e),
    sharedSettings: shared ? join(shared, "settings.json") : null,
    pins: place("pins.json", join(b.cdir, "pins.json")),
    searches: place("searches.json", join(b.cdir, "searches.json")),
    todos: place("todos.json", join(b.cdir, "todos.json")),
    view: place("view.json", join(b.cdir, "view.json")),
    instructions: e.OMA_ZOTERO_INSTRUCTIONS || place("instructions.md", join(b.cdir, "instructions.md")),
    prompts: e.OMA_ZOTERO_PROMPTS_DIR || place("prompts", join(b.cdir, "prompts")),
    taxonomies: place("taxonomies", join(b.cdir, "taxonomies")),
    taxonomyState: place("taxonomy.json", join(b.state, "taxonomy.json")),
    chats: place("chats", join(b.state, "chats")),
    artifacts: typeof artifactsDir === "string" && artifactsDir.trim() ? join(expandHome(artifactsDir.trim(), b.home)) : place("artifacts", join(b.state, "artifacts")),
    extract: join(b.cdir, "extract.json"),
    runnerTasks: join(b.state, "tasks"),
    runnerState: b.state,
    promptVersions: join(b.state, "prompt-versions.json"),
    keyTests: join(b.state, "key-tests.json"),
    modelsCache: join(b.cache, "models.json"),
    providerCache: b.cache,
    backups: join(b.cdir, "sync-backups"),
    configDir: b.cdir,
    syncDir: syncDir,
    marker: shared ? join(shared, MARKER) : null,
    stignore: syncDir ? join(syncDir, ".stignore") : null,
    machine: typeof name === "string" && name.trim() ? name.trim() : String(e.hostname || "").trim() || "this machine",
    readOnly: false,
    problems: problems
  }
  if (syncDir && !(probe && probe.syncMarker)) {
    out.readOnly = true
    problems.push("sync-unavailable")
  }
  return out
}

function problemText(code, paths) {
  if (code === "sync-unavailable") return "Sync folder not found: " + paths.syncDir
  if (code === "sync-dir-invalid") return "Sync folder ignored: a folder path starts with / or ~/"
  return String(code)
}
if (typeof module !== "undefined") module.exports = {
  MARKER: MARKER, SYNCED: SYNCED, SETTING_SCOPES: SETTING_SCOPES, settingsFile: settingsFile, resolve: resolve, problemText: problemText
}
```

```js
// and put back together; every key the Settings view can write has a side.
const test = require("node:test");
const assert = require("node:assert/strict");
const P = require("../lib/Paths.js");
const S = require("../lib/Settings.js");

const FILE = {
  general: { port: 1234, promptCommand: ["node", "x.mjs"], syncDir: "/s", machineName: "arch", keyDelay: 200, citationStyle: "apa", automationHost: "arch" },
  providers: { claude: { enabled: true } },
  defaults: { autoExtract: true },
  tasks: { defaultTask: "next" },
  status: { tags: ["s/to read"] },
  rules: { quotes: true },
};

test("every general key has a side", () => {
  for (const key of Object.keys(S.GENERAL_DEFAULTS)) assert.ok(P.SETTING_SCOPES["general." + key], "general." + key);
});

test("every section the Settings view writes is shared", () => {
  const file = S.toFile({
    maxResults: 100,
    providers: { claude: { enabled: true } },
    endpoints: [{ id: "lab", name: "Lab", baseURL: "https://gw/v1", enabled: true }],
    defaults: { prompts: { model: "m", effort: "low" }, autoExtract: true },
    tasks: { statuses: [{ id: "a", name: "A", group: "active" }], defaultTask: "a" },
    paperStatuses: ["x"],
    rules: { quotes: true },
  });
  for (const section of Object.keys(file)) if (section !== "general") assert.equal(P.SETTING_SCOPES[section], "shared", section);
});

test("splitSettings: the machine's keys on the machine, the rest shared", () => {
  const { machine, shared } = P.splitSettings(FILE, true);
  assert.deepEqual(machine, { general: { port: 1234, promptCommand: ["node", "x.mjs"], syncDir: "/s", machineName: "arch" } });
  assert.deepEqual(shared, {
    general: { keyDelay: 200, citationStyle: "apa", automationHost: "arch" },
    providers: { claude: { enabled: true } }, defaults: { autoExtract: true }, tasks: { defaultTask: "next" }, status: { tags: ["s/to read"] }, rules: { quotes: true },

test("split then combined: the same file; sync off: all of it on the machine", () => {
  const { machine, shared } = P.splitSettings(FILE, true);
  assert.deepEqual(P.combineSettings(machine, shared), FILE);
  assert.deepEqual(P.splitSettings(FILE, false), { machine: FILE, shared: null });

test("unknown keys and sections stay on the machine, nothing is dropped", () => {
  const { machine, shared } = P.splitSettings({ general: { someday: 1 }, newSection: { a: 1 }, maxResults: 80 }, true);
  assert.deepEqual(machine, { general: { someday: 1 }, newSection: { a: 1 }, maxResults: 80 });
  assert.deepEqual(shared, {});

test("combineSettings: the shared file wins shared keys only; where it lacks one, the machine's stays", () => {
  assert.deepEqual(P.combineSettings({ general: { port: 1, keyDelay: 300 } }, { general: { keyDelay: 150, port: 2 } }), { general: { port: 1, keyDelay: 150 } });

  assert.deepEqual(P.combineSettings({ maxResults: 80 }, null), { maxResults: 80 });
```

```js
// ------------------------------------------------------------ two settings files

function scopeOf(section, key) {
  return SETTING_SCOPES[key === undefined ? section : section + "." + key] || "machine"
}

// The settings file (today's shape) → { machine, shared }; sync off: all of it on the machine.
function splitSettings(file, syncOn) {
  var f = clone(isObject(file) ? file : {})
  if (!syncOn) return { machine: f, shared: null }
  var machine = {}
  var shared = {}
  for (var sec in f) {
    if (sec === "general" && isObject(f.general)) {
      var mg = {}
      var sg = {}
      for (var k in f.general) (scopeOf("general", k) === "shared" ? sg : mg)[k] = f.general[k]
      if (Object.keys(mg).length) machine.general = mg
      if (Object.keys(sg).length) shared.general = sg
    } else if (scopeOf(sec) === "shared") shared[sec] = f[sec]
    else machine[sec] = f[sec]
  }
  return { machine: machine, shared: shared }
}

// The two files → one in today's shape: the shared file wins the shared keys; where it lacks
// one, the machine file's value stays. No shared file: the machine file as it is.
function combineSettings(machineRaw, sharedRaw) {
  var out = clone(isObject(machineRaw) ? machineRaw : {})
  if (!isObject(sharedRaw)) return out
  for (var sec in sharedRaw) {
    if (sec === "general" && isObject(sharedRaw.general)) {
      if (!isObject(out.general)) out.general = {}
      for (var k in sharedRaw.general) if (scopeOf("general", k) === "shared") out.general[k] = clone(sharedRaw.general[k])
    } else if (scopeOf(sec) === "shared") out[sec] = clone(sharedRaw[sec])
  }
  return out
}

function jsonText(x) {
  return JSON.stringify(x, null, 2) + "\n"
}

// JSON with its keys sorted, to compare two settings objects whatever order they were written in.
function canonical(x) {
  if (Array.isArray(x)) return "[" + x.map(canonical).join(",") + "]"
  if (isObject(x)) return "{" + Object.keys(x).sort().map(function (k) { return JSON.stringify(k) + ":" + canonical(x[k]) }).join(",") + "}"
  return JSON.stringify(x)
}

// What saving the settings file (today's shape) writes: { machine (the machine file's text), shared
// (the shared file's, or null: not syncing, or the folder is missing), refused (why a shared change
// wasn't saved, else "") }. currentShared: the shared file as read. While the sync folder is missing
// the machine's own keys still save; a change to a shared one is refused, never written elsewhere.
function settingsSave(file, paths, currentShared) {
  var parts = splitSettings(file, !!(paths && paths.syncDir))
  if (!parts.shared) return { machine: jsonText(parts.machine), shared: null, refused: "" }
  if (!paths.readOnly) return { machine: jsonText(parts.machine), shared: jsonText(parts.shared), refused: "" }
  var changed = canonical(parts.shared) !== canonical(isObject(currentShared) ? currentShared : {})
  return { machine: jsonText(parts.machine), shared: null, refused: changed ? problemText("sync-unavailable", paths) : "" }
}
```

```js
function withSyncDir(file, dir) {
  var f = clone(isObject(file) ? file : {})
  delete f.syncDir
  if (!isObject(f.general)) f.general = {}
  if (dir) f.general.syncDir = dir
  else delete f.general.syncDir
  if (!Object.keys(f.general).length) delete f.general
  return f
}

// Every path syncPlan may look at, for the caller to probe first (each: does it exist).
function probePaths(env, settings, nextSyncDir) {
  var local = resolve(env, withSyncDir(settings, null), { syncMarker: true })
  var before = resolve(env, settings, { syncMarker: true })
  var after = resolve(env, withSyncDir(settings, nextSyncDir), { syncMarker: true })
  var out = [local.settings]
  SYNCED.forEach(function (k) { out.push(local[k], before[k], after[k]) })
  if (after.marker) out.push(after.marker, after.stignore)
  return out.filter(function (p, i) { return out.indexOf(p) === i })
}

// The steps that turn the sync folder on (fill: the first machine; join: the folder already has
// data, yours goes to a backup) or off (leave: the folder's files come back here). settings: the
// combined settings file (combineSettings); probe: { exists: { path: bool }, date: "YYYY-MM-DD-HHMMSS",
// now: ISO date }. The machine settings file, which carries syncDir, is always written last.
function syncPlan(env, settings, nextSyncDir, probe) {
  var p = probe || {}
  var exists = p.exists || {}
  var target = withSyncDir(settings, nextSyncDir)
  var local = resolve(env, withSyncDir(settings, null), { syncMarker: true })
  var before = resolve(env, settings, { syncMarker: true })
  var after = resolve(env, target, { syncMarker: true })
  if (after.problems.length) return { kind: "invalid", ops: [], message: problemText(after.problems[0], after) }
  if (before.syncDir === after.syncDir) return { kind: "none", ops: [] }
  if (before.syncDir && after.syncDir) return { kind: "refused", ops: [], message: "Clear the sync folder first, then set the new one" }
  var backup = join(local.backups, p.date)
  var synced = after.syncDir ? after : before
  var moving = SYNCED.filter(function (k) { return local[k] !== synced[k] })
  var ops = []
  if (!after.syncDir) {
    ops.push({ op: "mkdir", to: backup })
    // Only what the folder has a copy of is replaced: with the folder gone, your files stay as they are.
    moving.forEach(function (k) {
      if (!exists[before[k]]) return
      if (exists[local[k]]) ops.push({ op: "move", from: local[k], to: join(backup, baseName(local[k])) })
      ops.push({ op: "copy", from: before[k], to: local[k] })
    })
    ops.push({ op: "write", to: local.settings, text: jsonText(target) })
    return { kind: "leave", ops: ops }
  }
  var parts = splitSettings(target, true)
  if (exists[after.marker]) {
    ops.push({ op: "mkdir", to: backup })
    moving.forEach(function (k) {
      if (exists[local[k]]) ops.push({ op: "move", from: local[k], to: join(backup, baseName(local[k])) })
    })
    if (exists[local.settings]) ops.push({ op: "copy", from: local.settings, to: join(backup, baseName(local.settings)) })
    ops.push({ op: "write", to: local.settings, text: jsonText(parts.machine) })
    return { kind: "join", ops: ops }
  }
  ops.push({ op: "mkdir", to: join(after.syncDir, "shared") })
  moving.forEach(function (k) {
    if (exists[local[k]]) ops.push({ op: "copy", from: local[k], to: after[k] })
  })
  ops.push({ op: "write", to: after.sharedSettings, text: jsonText(parts.shared) })
  if (!exists[after.stignore]) ops.push({ op: "write", to: after.stignore, text: STIGNORE })
  ops.push({ op: "write", to: after.marker, text: jsonText({ version: 1, created: p.now, by: after.machine }) })
  ops.push({ op: "write", to: local.settings, text: jsonText(parts.machine) })
  return { kind: "fill", ops: ops }
}

// A plan's steps as the arguments of scripts/sync-apply.sh.
function opsArgv(ops) {
  var out = []
  ;(ops || []).forEach(function (o) {
    if (o.op === "mkdir") out.push("mkdir", o.to)
    else if (o.op === "write") out.push("write", o.to, o.text)
    else out.push(o.op, o.from, o.to)
  })
  return out
}
```

```bash
#!/bin/bash
# The steps of a sync-folder change (lib/Paths.js syncPlan), in order; stops at the first that fails
# and names it on stderr. Each step is safe to run again: a rerun after a failure finishes the job.
#   sync-apply.sh probe PATH...         one line per path: 1 if it exists, else 0
#   sync-apply.sh STEP... where STEP is
#     mkdir DIR                         the folder and its parents
#     copy FROM TO                      a file, or a folder's contents merged into TO; skipped if FROM is gone
#     move FROM TO                      skipped if FROM is gone (a rerun after it moved)
#     write PATH TEXT                   TEXT into PATH, through a temporary file renamed over it
set -euo pipefail

fail() { echo "sync-apply: $* failed" >&2; exit 1; }

if [[ ${1:-} == probe ]]; then
  shift
  for p in "$@"; do if [[ -e $p || -L $p ]]; then echo 1; else echo 0; fi; done
  exit 0
fi

while (( $# )); do
  step=$1
  shift
  case $step in
    mkdir)
      (( $# >= 1 )) || fail "mkdir (no folder given)"
      mkdir -p -- "$1" || fail "mkdir $1"
      shift ;;
    copy)
      (( $# >= 2 )) || fail "copy (two paths needed)"
      from=$1 to=$2
      shift 2
      if [[ -d $from ]]; then
        { mkdir -p -- "$to" && rsync -a -- "$from/" "$to/"; } || fail "copy $from $to"
      elif [[ -e $from ]]; then
        { mkdir -p -- "$(dirname -- "$to")" && cp -p -- "$from" "$to"; } || fail "copy $from $to"
      fi ;;
    move)
      (( $# >= 2 )) || fail "move (two paths needed)"
      from=$1 to=$2
      shift 2
      if [[ -e $from || -L $from ]]; then
        { mkdir -p -- "$(dirname -- "$to")" && mv -- "$from" "$to"; } || fail "move $from $to"
      fi ;;
    write)
      (( $# >= 2 )) || fail "write (a path and a text needed)"
      path=$1 text=$2
      shift 2
      tmp="$path.$$.tmp"
      if ! { mkdir -p -- "$(dirname -- "$path")" && printf '%s' "$text" > "$tmp" && mv -f -- "$tmp" "$path"; }; then
        rm -f -- "$tmp" 2>/dev/null || true
        fail "write $path"
      fi ;;
    *) fail "unknown step $step" ;;
  esac
done
```

The `rm -f ... 2>/dev/null || true` matters: when the write failed because the folder is a file, `rm` fails too, and under `set -e` the script would exit before naming the step.

```js
// The runner's only path code: lib/Paths.js, shared with the launcher and the macOS app. An
// installed runner has its copy next to this file (scripts/copy-shared-paths.sh); a checkout
// reads the repository's. Every call reads the machine settings file again: runner commands
// are short-lived, and a sync folder set a moment ago must count.
import { readFileSync, existsSync } from "node:fs";
import { hostname } from "node:os";
import { createRequire } from "node:module";

const require = createRequire(import.meta.url);

function load() {
  try {
    return require("./shared-paths.cjs");
  } catch {
    return require("../../lib/Paths.js");
  }
}

export const Paths = load();

function readJson(path) {
  try {
    return JSON.parse(readFileSync(path, "utf8"));
  } catch {
    return null;
  }
}

function envOf(env) {
  return {
    HOME: env.HOME, XDG_CONFIG_HOME: env.XDG_CONFIG_HOME, XDG_STATE_HOME: env.XDG_STATE_HOME, XDG_CACHE_HOME: env.XDG_CACHE_HOME,
    OMA_ZOTERO_PROMPTS_DIR: env.OMA_ZOTERO_PROMPTS_DIR, OMA_ZOTERO_INSTRUCTIONS: env.OMA_ZOTERO_INSTRUCTIONS,
    hostname: env.OMA_ZOTERO_HOSTNAME || hostname(),
  };
}

export function machineSettings(env = process.env) {
  return readJson(Paths.settingsFile(envOf(env)));
}

export function paths(env = process.env) {
  const e = envOf(env);
  const raw = machineSettings(env);
  const first = Paths.resolve(e, raw, { syncMarker: true });
  return Paths.resolve(e, raw, { syncMarker: !!first.marker && existsSync(first.marker) });
}

// The settings in today's shape: the machine file, and the shared one when syncing.
export function combinedSettings(env = process.env) {
  const p = paths(env);
  return Paths.combineSettings(machineSettings(env), p.sharedSettings ? readJson(p.sharedSettings) : null);
}

// A write under a sync folder that isn't there would start a second copy of your data: refused.
export function assertWritable(path, env = process.env) {
  const p = paths(env);
  if (p.readOnly && p.syncDir && (path === p.syncDir || String(path).startsWith(p.syncDir + "/"))) {
    throw new Error(Paths.problemText("sync-unavailable", p));
  }
}
```

`daemon/lib/atomic.mjs`:

```js
// Writes that never leave a half-written file, for the files a sync folder carries: a temporary
// file in the same folder, renamed over the old one. Refused while the sync folder is missing.
import { writeFileSync, renameSync, mkdirSync, rmSync } from "node:fs";
import { dirname } from "node:path";
import { assertWritable } from "./paths.mjs";

export function ensureDir(dir, env = process.env) {
  assertWritable(dir, env);
  mkdirSync(dir, { recursive: true });
}

export function writeAtomic(path, text, env = process.env) {
  assertWritable(path, env);
  mkdirSync(dirname(path), { recursive: true });
  // a temporary name of its own: runs write at the same time (the rename is atomic, the last one wins)
  const tmp = `${path}.${process.pid}.${Math.random().toString(36).slice(2, 8)}.tmp`;
  try {
    writeFileSync(tmp, text);
    renameSync(tmp, path);
  } catch (e) {
    rmSync(tmp, { force: true });
    throw e;
  }
}
```
